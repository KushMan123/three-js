# Main Screen Video Directory

Place your main screen animation video file here.

**Required file:** `mainScreen_animation.mp4`

## Video Requirements:
- Format: MP4 (H.264 codec recommended)
- Must be muted (no audio)
- Will loop automatically
- Recommended: 30 FPS for smooth playback

The video will automatically replace the static texture (`command_center_mainScreen.jpg`) when loaded.
